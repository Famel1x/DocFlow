# Полное руководство по правилам преобразования таблиц в FAQ

Сервис предоставляет гибкий декларативный синтаксис правил для извлечения данных из таблиц любых форматов (PDF, DOCX, PPTX, XLSX), включая сложные структуры с объединенными ячейками по горизонтали и вертикали.

---

## 1. Структура правила

Правило состоит из двух частей:
1. **Директивы** (строки, начинающиеся со знака `@`) — задают режим парсинга, количество строк шапки, группировку, фильтры и разделители.
2. **Шаблон** (строки без знака `@`) — задает вид готового текста с подстановкой значений ячеек в фигурных скобках `{...}`.

---

## 2. Основные директивы (`@...`)

| Директива | Параметр / Значение | Назначение |
| :--- | :--- | :--- |
| `@mode` | `row`, `column`, `kv`, `matrix`, `group`, `flat` | Выбор алгоритма обхода таблицы. По умолчанию `row`. |
| `@header_rows` | Число (например, `1`, `2`) | Количество строк шапки таблицы. При `2` заголовки объединяются через ` > `. |
| `@header_cols` | Число (например, `1`) | Количество столбцов слева, которые являются названиями строк (для `@mode matrix`). |
| `@skip_empty` | Без параметров | Пропускать полностью пустые строки и ячейки. |
| `@separator` | Текст (например, `; `, `, `, ` \| `) | Разделитель значений при склейке (по умолчанию `; `). |
| `@group_by` | Номер колонки или имя заголовка | Колонка для группировки в `@mode group`. |
| `@merge_repeated`| Без параметров | Объединять повторяющиеся/объединенные значения в группе. |
| `@enumerate` | Без параметров | Добавить автоматическую сквозную нумерацию строк (`1. `, `2. `...). |
| `@prefix` | Текст (например, `[FAQ] `) | Добавить префикс к каждой строке вывода. |
| `@data_rows` | Диапазон `N:M` (например, `1:10`) | Обрабатывать только строки с $N$ по $M$ (среди строк данных). |
| `@data_cols` | Диапазон `N:M` (например, `0:4`) | Обрабатывать только колонки с индексами от $N$ до $M$. |

---

## 3. Переменные шаблона (`{...}`)

* **`{0}`, `{1}`, `{2}`, ...** — значение ячейки по порядковому номеру колонки (0 — первый столбец).
* **`{ИмяЗаголовка}`** — значение ячейки по точному совпадению с текстом заголовка из шапки таблицы.
* **`{_row}`** — порядковый номер текущей строки данных (начиная с 1).
* **`{_group}`** — текущее имя группы (в режиме `@mode group`).
* **`{_all}`** — все заполненные ячейки текущей строки, склеенные через `@separator`.
* **`{_row_header}`**, **`{_col_header}`**, **`{_value}`** — используются в режиме `@mode matrix`.

---

## 4. Подробное описание режимов (`@mode`)

### 4.1. Режим `row` (построчный)
Используется для стандартных таблиц-списков, где каждая строка — отдельный объект.

**Пример правила:**
```text
@mode row
Вопрос: {0}. Ответ: {1} (Категория: {2})
```
или по именам колонок:
```text
@mode row
@skip_empty
@enumerate
Вопрос: {Вопрос}
Ответ: {Ответ}
```

---

### 4.2. Режим `group` (группировка по категориям / объединенным ячейкам)
Идеален для таблиц, где в первом столбце объединено несколько строк одной категории (например, «Бытовая техника», «Компьютеры»).

**Пример правила:**
```text
@mode group
@group_by 0
@merge_repeated
@header_rows 2
Товар: {1} | Базовая цена: {2} (Гарантия: {3}) | Премиум: {4} (Гарантия: {5})
```
**Результат:**
```text
[Бытовая техника]
  Товар: Стиральная машина Alfa | Базовая цена: 35 000 (Гарантия: 12 мес) | Премиум: 45 000 (Гарантия: 36 мес)
  Товар: Холодильник FrostPro | Базовая цена: 52 000 (Гарантия: 12 мес) | Премиум: 68 000 (Гарантия: 36 мес)

[Компьютеры]
  Товар: Ноутбук WorkBook 14 | Базовая цена: 65 000 (Гарантия: 12 мес) | Премиум: 85 000 (Гарантия: 24 мес)
```

---

### 4.3. Режим `matrix` (перекрестная матрица)
Используется для таблиц прав доступа, тарифов, расписаний или сравнений параметров, где на пересечении строки и столбца находится статус или значение.

**Пример правила:**
```text
@mode matrix
@header_cols 1
Для роли "{_row_header}" доступ к разделу "{_col_header}": {_value}
```
**Результат:**
```text
Для роли "Стажер" доступ к разделу "Модуль CRM": Чтение
Для роли "Стажер" доступ к разделу "Бухгалтерия": Нет доступа
Для роли "Менеджер продаж" доступ к разделу "Модуль CRM": Полный доступ
```

---

### 4.4. Режим `kv` (ключ — значение)
Применяется для параметров оборудования, анкет, карточек товаров, где первый столбец содержит название параметра, а второй — его значение.

**Пример правила:**
```text
@mode kv
Параметр {_key}: {_value}
```

---

### 4.5. Режим `column` (по колонкам)
Каждая колонка превращается в отдельный блок или список.

**Пример правила:**
```text
@mode column
@separator , 
Список значений для поля "{_header}": {_values}
```

---

### 4.6. Режим `flat` (сплошной текст)
Извлекает все ячейки таблицы подряд в одну строку через разделитель. Удобно для быстрого текстового поиска ключевых слов.

---

## 5. Как сохранить результат в итоговый документ

1. Откройте файл и таблицу.
2. Примените правило преобразования или отправьте в GigaChat.
3. Отредактируйте текст превью или ответ LLM при необходимости.
4. Нажмите кнопку **«💾 Зафиксировать текст таблицы»**.
5. Когда все таблицы в документе зафиксированы, в шапке активируется кнопка **«📥 Скачать итоговый документ»**, которая сформирует готовый файл с замененными таблицами.
