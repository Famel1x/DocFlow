# Политика безопасности (Security Policy)

Команда проекта **DocuFlow AI** уделяет пристальное внимание безопасности пользовательских данных, защите ключей доступа и конфиденциальности загружаемых документов.

---

## Поддерживаемые версии (Supported Versions)

Мы выпускаем обновления безопасности и исправления для следующих версий:

| Версия | Поддержка безопасности |
| :--- | :--- |
| 1.0.x (Current / Main) | :white_check_mark: Поддерживается |
| < 1.0.0 | :x: Не поддерживается |

---

## Сообщение об уязвимости (Reporting a Vulnerability)

Если вы обнаружили потенциальную уязвимость безопасности в DocuFlow:

1. **Не создавайте публичные Issue в репозитории.**
2. Отправьте конфиденциальный отчет через [GitHub Security Advisory](https://github.com/) во вкладке **Security -> Report a vulnerability** либо свяжитесь с мейнтейнерами по электронной почте: `security@docuflow.local`.
3. В отчете укажите:
   - Подробное описание уязвимости.
   - Пошаговые инструкции или сценарий (PoC) для воспроизведения.
   - Оценку потенциального воздействия (утечка данных, отказ в обслуживании, RCE и т.д.).
   - Затронутые компоненты (парсинг файлов, клиент GigaChat, OCR, веб-интерфейс).

### Регламент ответа:
- **Первичный ответ:** в течение 48 часов после получения обращения.
- **Оценка и подтверждение:** в течение 5 рабочих дней.
- **Выпуск патча:** мы стремимся выпускать исправления критических уязвимостей в кратчайшие сроки до публичного раскрытия информации.

---

## Рекомендации по безопасной эксплуатации

* **Ключи API и токены GigaChat:** Никогда не коммитьте в систему контроля версий файл `settings.json` с заполненными полями `auth_key`. Добавьте локальные конфигурационные файлы в `.gitignore`.
* **Сертификаты Минцифры и закрытые ключи:** Храните файлы `*.key` и `*.pem` в каталогах с ограниченными правами доступа операционной системы (только для чтения текущим пользователем).
* **Загрузка непроверенных документов:** Обработка файлов PDF, DOCX, PPTX и XLSX производится через сторонние парсеры (`pdfplumber`, `python-docx`, `openpyxl`, `python-pptx`). Не открывайте в производственной среде файлы из недоверенных источников без предварительной антивирусной проверки.
* **Локальный запуск:** По умолчанию сервер запускается на `0.0.0.0:8000` для локальной работы. При размещении в сети используйте Reverse Proxy (Nginx / Caddy) с настроенным HTTPS и ограничением доступа.
