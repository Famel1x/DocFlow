Справочник синтаксиса и примеры правил

По умолчанию

@mode row

Построчный обход стандартных списков. Каждая строка данных формирует один элемент FAQ.

@mode row
@skip_empty
Вопрос: {0}. Ответ: {1}
Объединенные ячейки

@mode group

Группировка строк по объединенному столбцу (например, категория товаров или фаза проекта).

@mode group
@group_by 0
@merge_repeated
Товар: {1} | Цена: {2}
Матрицы и права

@mode matrix

Перекрестная таблица (строка × столбец). Для прав доступа, тарифов, расписаний.

@mode matrix
@header_cols 1
Для роли "{_row_header}" доступ к "{_col_header}": {_value}
Ключ-значение

@mode kv

Для карточек товаров и спецификаций, где колонка 0 — параметр, колонка 1 — значение.

@mode kv
Параметр {_key}: {_value}
По колонкам

@mode column

Чтение таблицы сверху-вниз по вертикальным колонкам.

@mode column
@separator , 
Поле "{_header}": {_values}
Сплошной поток

@mode flat

Извлекает все непустые ячейки подряд через разделитель для общего текстового контекста.

@mode flat
@separator ;
Директива Пример Описание
@header_rows N @header_rows 2 Количество строк шапки. При $N > 1$ заголовки объединяются через > .
@header_cols N @header_cols 1 Количество столбцов-заголовков строк слева (используется в @mode matrix).
@group_by N @group_by 0 Номер колонки или имя заголовка для группировки в @mode group.
@merge_repeated @merge_repeated Автоматически объединять повторяющиеся и объединенные ячейки в группе.
@skip_empty @skip_empty Игнорировать полностью пустые строки и ячейки.
@separator TEXT @separator ; Разделитель ячеек при объединении по умолчанию.
@enumerate @enumerate Добавить автоматическую нумерацию строк (1., 2., 3...).
@prefix TEXT @prefix [FAQ] Добавить префикс к каждой сформированной строке.
@data_rows N:M @data_rows 1:10 Ограничить диапазон обрабатываемых строк данных (с 1 по 10).
@data_cols N:M @data_cols 0:3 Ограничить диапазон обрабатываемых колонок (с 0 по 3).
Переменная Где доступна Значение
{0}, {1}, {2}... Все режимы Значение ячейки по индексу колонки (0 — первая колонка).
{ИмяЗаголовка} Все режимы Значение ячейки по точному совпадению с текстом в шапке таблицы.
{_row} row, group Порядковый номер строки данных (начиная с 1).
{_group} group Название текущей группы категорий.
{_all} row, group Все заполненные ячейки строки через разделитель @separator.
{_row_header} matrix Заголовок строки на пересечении в матрице.
{_col_header} matrix Заголовок столбца на пересечении в матрице.
{_value} matrix Значение на пересечении строки и столбца.
{_key} kv Ключ (параметр из первой колонки).
Пример 1: Вопросы и ответы с категорией
@mode row
@skip_empty
@enumerate
Вопрос: {Вопрос}
Ответ: {Ответ} (Категория: {Категория})
Пример 2: Сложный прайс с объединенными категориями
@mode group
@group_by 0
@merge_repeated
@header_rows 2
Товар: {1} | Базовая цена: {2} | Премиум: {4}
Пример 3: Матрица доступов и ролей сотрудников
@mode matrix
@header_cols 1
Роль: {_row_header} -> Доступ к {_col_header}: {_value}
